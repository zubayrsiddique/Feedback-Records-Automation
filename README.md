# Feedback-Records-Automation
An automated Make.com workflow that monitors customer feedback in Google Sheets, uses Google Gemini AI to analyze sentiment and craft tailored responses, and automatically sends replies via Gmail.
Key Features: 
Trigger: Watches for new rows/feedback submitted to a Google Sheets spreadsheet. 
AI Analysis & Sentiment Routing: Uses Google Gemini AI to process customer feedback, iterate over the entries, and route them based on sentiment (Positive, Negative, Neutral). 
Automated Email Replies: Sends personalized, context-aware email responses to customers using Gmail based on the detected sentiment.
